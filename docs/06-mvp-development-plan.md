# 1. Purpose

This document defines the implementation roadmap for JobMate V1.

The goal is to transform the product specifications into a publicly usable MVP.

The development process should prioritize:

1. Working functionality
2. Reliability
3. User experience
4. Security
5. AI quality
6. Maintainability
7. Zero/low upfront cost

The target is not simply to finish code.

The target is:

> **Build a product that a real job seeker can use without developer assistance.**
