# 1. Purpose

This document defines the complete user journey through JobMate V1.

The goal is to ensure that:

- The user always knows what to do next.
- The workflow has minimal friction.
- The application feels responsive.
- Users receive meaningful feedback during processing.
- Errors are recoverable.
- Free and paid experiences are clearly separated.
- Users can review AI-generated content before using it.

The primary user journey is:

```text
Landing Page
      ↓
Upload Resume
      ↓
Add Job Description
      ↓
Validate Inputs
      ↓
Analyze Job
      ↓
Free Results
      ↓
Paid Application Package
      ↓
Generate Application
      ↓
Review & Edit
      ↓
Copy / Download
